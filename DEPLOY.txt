Deploy Steps (Free)
-------------------
1. Go to https://render.com and sign up (free, use Google or email).

2. Click "New +" → "Web Service".

3. Connect a GitHub account (or use "Public Git repository" / upload).
   - Easiest: Create a free GitHub repo, upload the porter_catering folder, then connect it.
   - Or use Render’s manual deploy if available.

4. Settings:
   - Name: porter-catering (or any name)
   - Environment: Python
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app
   - Instance Type: Free

6. Click "Create Web Service".
